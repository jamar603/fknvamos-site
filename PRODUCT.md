# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS, no build step. Deployed on GitHub Pages. Edited in VS Code.
Payments through Stripe Payment Links (one link per product, set in `data/products.js`).

## Users

Young streetwear buyers who discover FKN VAMOS on Instagram (@fknvamos), mostly on a phone,
arriving from a bio link or a story swipe. Job: see the drop, pick a size, pay fast.

## Product Purpose

Online shop for the FKN VAMOS streetwear brand. Turns Instagram attention into orders without
DM back-and-forth. Success = a visitor from Instagram reaches Stripe checkout in a few taps.

## Positioning

Independent streetwear label sold direct from its own site and Instagram community.
Name reads as "f*cking vamos" (let's go): energy, momentum, attitude.

## Capabilities and Constraints

- Product catalog lives in one editable file (`data/products.js`).
- Size selection per product; checkout opens the product's Stripe Payment Link.
- No server, no database, no accounts.
- Undecided: real product list, prices, sizes, shipping zones, return policy, contact email.

## Brand Commitments

- Name: FKN VAMOS. Instagram: https://instagram.com/fknvamos
- Logo, fonts and colors: not supplied yet.

## Evidence on Hand

None yet. No product photos, prices, reviews or press supplied. Do not invent testimonials,
follower counts or sales figures. Placeholders must be clearly marked for replacement.

## Product Principles

1. Phone first: the Instagram visitor is the main visitor.
2. Shortest path from product to payment.
3. The client must be able to update products without touching layout code.
4. Attitude over decoration: the brand voice carries the page.
